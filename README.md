# Expense Tracker
A simple desktop application to track personal expenses with real-time currency conversion.

## Features
- Add and delete expenses by category
- Real time currency conversion for TRY, USD, EUR, GBP using the Frankfurter API
- Persistent Storage, expenses are saved in a csv file and reloded at start

## How to run

1. Clone the repository
    ```
    git clone https://github.com/xayker/expense-tracker.git
    ```
2. Install dependencies
   ```
    pip install requests
   ```
3. Run the app
    ```
    python main.py
   ```
